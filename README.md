One line, 200 characters or fewer: the excuse an AI agent gives its human after losing a bounty. The program writes that single deterministic line to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
cat /tmp/out/entry.txt
```
